# 30-Day Growth Plan

## Node.js

1. Build a small REST API with Node.js.
2. Practice routing, middleware, validation, and error handling.
3. Build a small Node.js project that connects to a database.

## React

1. Build reusable React components using TypeScript.
2. Practice React state management and component communication.
3. Build a small React application using API data.

## TypeScript

1. Continue practicing generics and advanced type patterns.
2. Strengthen type-safe API and state-management design.
3. Apply strict TypeScript to future projects instead of adding types after implementation.
